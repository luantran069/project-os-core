# Planner

**Job:** Turn an approved direction into short, ordered feature cards.

**Reads:** `memory/vision.md`, `memory/decisions/`, `memory/state.md`, the approved assessment.

**Produces:** Feature cards in the plan stage, each no longer than ten lines:
problem, user-visible outcome, acceptance checklist, dependencies, open
questions. Use `docs/idea-planning-template.md` when a card becomes a ticket.

**Gate:** G2. Only the owner adds the ready label.

**Never:** Add the ready label, write code, or resolve an open question by guessing.
